# Internship Application Tracker

A productivity web app for organizing internship applications, statuses, deadlines, notes, and follow-ups.

## Features

- Create an account
- Login and logout
- Save each user's applications separately in browser localStorage
- Add internship applications
- Track company name, position, status, deadline, and notes
- Edit and delete saved applications
- Search by company or position
- Filter by status
- Dashboard stats for total applications, applied roles, interviews, and upcoming deadlines
- Works as a static website, so it can be published with GitHub Pages

## Important Note

This version uses browser localStorage for login and saved data. It is good for a portfolio/demo project, but it is not a real secure authentication system. For a real production app, use a backend database and secure authentication.

## Tech Used

- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run

Open `index.html` in your browser.
